## 技术栈

- HTML5（语义化标签）
- CSS3（Grid / Flexbox 布局、渐变、动画、响应式设计）
- 原生 JavaScript（IntersectionObserver 滚动动画、数字滚动、移动端菜单）
- GitHub Pages（在线发布）

## 页面结构

| 区块 | 内容 |
| ---- | ---- |
| Hero | 姓名 + 渐变标题 + 滚动提示 |
| 关于我 | 个人介绍 + 统计卡片 |
| 技能 | 4 张技能卡 + 进度条动画 |
| 作品 | 课程作品展示 |
| 联系 | 邮箱 / GitHub 入口 |
