盒模型、层叠与继承

本节课重点：CSS 选择器优先级（Specificity）——当多条规则冲突时，浏览器到底听谁的？

一、盒模型（Box Model）

每一个 HTML 元素都是一个"盒子"，从外到内依次为：

  • margin（外边距）：盒子与其它盒子之间的空白，不会被背景填充，是透明的。
  • border（边框）：盒子的边框线，可设置粗细、样式、颜色。
  • padding（内边距）：内容与边框之间的距离，会被背景颜色填充。
  • content（内容区）：真正放文字、图片的地方。
margin 外边距
border 边框
padding 内边距
content
内容区（文字/图片）

盒子总宽度的计算公式（box-sizing: content-box 时）：

盒子总宽度 = content + padding*2 + border*2 + margin*2

盒子总高度的计算公式：

盒子总高度 = content + padding*2 + border*2 + margin*2

💡 小技巧：开发时常用 box-sizing: border-box，让 padding 和 border 都算在宽度内，宽高更可控。

box-sizing 对比实验

content-box 总宽度会被撑大

width: 200px + padding 40px + border 8px
= 248px

border-box 宽度固定为 200px

width: 200px 已包含 padding 和 border
= 200px

二、层叠（Cascade）

当多条 CSS 规则作用于同一个元素时，浏览器按下面顺序决定"听谁的"：

① !important > ② 行内 style > ③ ID 选择器 > ④ 类/属性/伪类 > ⑤ 元素/伪元素 > ⑥ 通配符 *

如果两边的优先级相同，就看书写顺序：后写的覆盖先写的（就近原则）。

演示：同等优先级，后写的生效

p.text { color: blue; }    /* 先写 */
p.text { color: red;  }    /* 后写 → 生效 */

这段文字由第一行规则上色（蓝）。

这段文字由第二行规则上色（红），演示"后写覆盖先写"。

三、继承（Inheritance）

某些属性会被子元素自动继承，某些则不会：

  • 可继承：文字类——color、font-family、font-size、line-height、text-align …
  • 不继承：盒子类——width、height、margin、padding、border、background …
我是父元素（color: #235b68; border: 3px solid）——所以文字是蓝色。

我是子元素，color 被继承，所以也是蓝色；但 border 不被继承，我没有边框。

💡 想强制继承/取消继承：inherit 或 initial、unset。

四、CSS 选择器优先级（Specificity）

优先级可以理解为一个"四位分数" (内联, ID, 类, 元素)，逐位比较，大的获胜：

选择器类型计数位数例子
行内样式 style=""(1,0,0,0)<p style="color:red">
ID 选择器(0,1,0,0)#intro
类 / 属性 / 伪类(0,0,1,0).text、[type="text"]、:hover、:nth-child(2)
元素 / 伪元素(0,0,0,1)div、::before
通配符 * 与组合器(0,0,0,0)*、空格、>、+、~ 不计分

分数计算举例

选择器ID类元素分数
p001(0,0,0,1)
.text010(0,0,1,0)
p.text011(0,0,1,1)
#intro p101(0,1,0,1)
#nav .item:hover120(0,1,2,0)
ul#nav li.active a113(0,1,1,3)

关键结论

  • #intro 永远赢过 .intro，不管 class 写多少；
  • 一个 .text 就能打败 div p a（(0,0,1,0) > (0,0,0,3)）；
  • !important 最高，但尽量不要乱用。

课堂挑战：谁赢？

① #box p (0,1,0,1)　vs　#box .txt (0,1,1,0)　→ .txt 赢

② div p span (0,0,0,3)　vs　.emu (0,0,1,0)　→ .emu 赢

③ p.title.item (0,0,2,1)　vs　#main (0,1,0,0)　→ #main 赢
