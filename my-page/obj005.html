JavaScript 对象

对象是 JavaScript 中最常用的数据结构，用来把一组相关的属性（数据）和方法（函数）打包在一起。本页练习对象的属性与方法、删除与判断、for...in 遍历，以及引用赋值后的共享变化。

① 属性与方法 ② 删除与判断 ③ for...in 遍历 ④ 引用赋值

1对象的属性与方法

使用对象字面量创建对象；用点语法或中括号语法访问属性；对象里的函数称为方法，方法中的 this 指向该对象本身。

// 创建对象
var student = {
    name: "小王",
    age: 20,
    hobbies: ["编程", "篮球"],
    sayHi: function () {
        return "大家好，我是 " + this.name;
    }
};

console.log(student.name);        // 点语法
console.log(student["age"]);      // 中括号语法
console.log(student.sayHi());     // 调用方法

        


        
        

            
2属性的删除与判断

            
delete 删除属性；用 in 运算符或 hasOwnProperty() 判断属性是否存在。注意 in 会沿原型链查找，而 hasOwnProperty 只看对象自身。

            
var book = { title: "网页设计", price: 59 };

delete book.price;
console.log(book.price);                 // undefined

console.log("title" in book);            // true
console.log("price" in book);            // false
console.log(book.hasOwnProperty("title")); // true

            

        


        
        

            
3for...in 遍历对象

            
for...in 循环会依次取出对象的键名（key），再通过 对象[key] 拿到对应的值。

            
var film = { name: "千与千寻", year: 2001, director: "宫崎骏" };

for (var key in film) {
    console.log(key + "：" + film[key]);
}

            

        


        
        

            
4引用赋值后的共享变化

            
对象是引用类型：var b = a 只是让 b 指向同一块内存，并没有复制。因此通过任意一个变量修改对象，另一个变量看到的也会同步变化。

            
var a = { score: 60 };
var b = a;              // b 和 a 指向同一个对象

b.score = 100;
console.log(a.score);   // 100 —— a 也跟着变了

// 想要互不影响，需要“深拷贝”出一个新对象：
var c = { ...a };       // 展开运算符复制
c.score = 0;
console.log(a.score);   // 仍然是 100
