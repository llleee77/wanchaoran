任务一 · new Swiper('#mySwi4', {…})

        
    
          
  • ① 无缝循环loop: true　索引从 0 数到 5 再回 0，首尾相接不跳帧
    • 
          
  • ② 3.2 秒自动翻页，手动后不停autoplay: { delay: 3200, disableOnInteraction: false }
    • 
          
  • ③ 圆点分页器可点击pagination: { el: '#pager', clickable: true }
    • 
          
  • ④ 初始效果 cubeeffect: 'cube'　页面加载即立方体
    •
