## 二、选的能力：keyboard + mousewheel

课堂没讲过、但这两个最实用：**不用鼠标也能讲完一页 PPT 式的演示**。两个我都做了，答辩时随便挑一个说。

```js
keyboard: {
  enabled: true,        // 打开键盘控制（← →）
  onlyInViewport: true  // 只有轮播在视口里才响应，避免页面滚到下方时误触
},
mousewheel: {
  enabled: true,          // 打开滚轮控制
  releaseOnEdges: true,   // 滑到第一张/最后一张时把滚动"还给"页面，不劫持
  thresholdDelta: 18,     // 滚轮增量超过 18 才翻页，防止手一抖跳两张
  forceToAxis: false      // 竖向滚轮也能翻（竖向滚动时页面会不动，见下方坑）
}
```

配套的开关（页面上三个 toggle）用的是模块自带的 `enable() / disable()`，不是重建实例：

```js
swiper.keyboard.enable();   swiper.keyboard.disable();
swiper.mousewheel.enable(); swiper.mousewheel.disable();
```

## 三、答辩第 1 问：这段代码什么意思？

**逐行翻译**：

- `keyboard.enabled: true` —— 给容器绑 `keydown`，监听 ← →；**不是** `keyboard: true`（那是 v6 的写法，v11 里传布尔值等于没开）。
- `onlyInViewport: true` —— 用 IntersectionObserver 判断轮播是否在视口内。不加的话，页面滚到底部看"需求对照表"时按方向键，上面的轮播会偷偷翻页。
- `mousewheel.releaseOnEdges: true` —— 到边界就 `preventDefault` 失效，滚轮回归页面滚动。**没有 loop 时这条才有意义**；本项目开了 `loop: true`，永远不会到边界，所以实际靠页面上那个开关来"放行"。
- `thresholdDelta: 18` —— 累积滚动量达到 18 才触发一次切换，是"防抖"。
- `forceToAxis: false` —— 允许竖向滚轮翻页；代价是**鼠标停在展台上时，竖向滚轮会被轮播吃掉**（页面不往下滚）。这正是一个要能说清楚的取舍：想要"滚轮翻页"就必然要抢滚动。

**第 2 问：AI 第一次给的哪里不对、你改了什么？**

| AI 第一次给的 | 现象 | 我改成 |
|---|---|---|
| `keyboard: true` | 按方向键毫无反应，控制台也不报错 | `keyboard: { enabled: true, onlyInViewport: true }` |
| 只引了 `swiper.min.js`（核心包）却写 `mousewheel` | 报 `swiper.mousewheel is undefined`，滚轮没反应 | 换 `swiper-bundle.min.js`（含 Mousewheel / Keyboard / Navigation 全部模块），或单独补引 `modules/mousewheel.min.js` |
| `new Swiper()` 之后又写 `swiper.changeEffect('fade')` | 报 `changeEffect is not a function` | Swiper 11 已移除该方法，改为 `destroy()` + 重新 `new`，并用 `initialSlide: 当前 realIndex` 保住位置 |
| 把我写循环切换特效的代码放在 `slideChange` 里 | 一换特效就无限重建、页面卡死 | 只在点击时重建一次 |

**第 3 问：新参数的作用？**

见上面逐行翻译。一句话版本：`onlyInViewport` 管"什么时候**不该**响应"，`thresholdDelta` 管"多大的动作才算一次"，`releaseOnEdges` 管"什么时候**该放手**"——三个都是**边界条件**参数，不是视觉效果参数。会调这些，才算真的会用插件。

## 四、答辩第 4 问：现场改 delay，说预期

现场操作：拖页面右下 `autoplay.delay` 滑块（或直接改输入框数字），页面会立刻回一段"预期"，照着念即可。

**表（背下来更稳）**

| delay | 相邻两次切换间隔 | speed=700ms 占一周期 | 观感 |
|---|---|---|---|
| 3200（默认） | 3.2s | 22% | 从容，每张停得住 |
| 1600 | 1.6s | 44% | 偏紧，翻页有点赶 |
| 800 | 0.8s | 88% | **动画还没走完就被推走，观感"卡带"** |

**必须说出口的三句**：

1. `delay` 是"**多久动一次**"，`speed` 是"**动多久**"，两者不叠加，别混；
2. 改的是 `swiper.params.autoplay.delay`，改完要 `autoplay.stop()` → `autoplay.start()` 才会立刻按新值重新计时，否则要等当前这一轮走完；
3. delay 不能小于过渡时长太多，否则视觉上就是"永远在动"。

**加分句**：如果把 `loop` 关掉、再配合 `releaseOnEdges: true`，还能演示"到最后一张把滚动还给页面"——这说明我确实读过参数，不是抄的。

## 五、思政衔接（30 秒，答辩收尾用）

我做的这六件展品里，前五件是 CSS 画的光——折射、霓虹、液光、光轨、光谱。第六件换成了一张真实存在的东西：**爱达·魔都号**。它是中国第一艘自己造的大型邮轮，13.55 万吨、323.6 米，2024 年 1 月 1 日从上海首航。

课上学的只是一个轮播插件，翻页、循环、缓动——都是"技术"。但这张图放在最后一页，是想说：**技术本身没有温度，是把它用在什么地方、为谁而做，才让它有了温度。** 天眼之父南仁东用 22 年把"不可能"变成"中国天眼"，我们今天的每一行代码，练的也是这个本事。

轮播会翻页，但**奋斗者的故事永远自动播放**。
