## 二、选的能力：浏览器历史（官方 demo `340-history.html`）

**效果**：地址栏跟着当前展品变（`#prism` → `#neon` → `#liquid`…），按浏览器的 ← 后退能回到上一张。

**为什么是它**：keyboard / mousewheel 课上讲过；zoom 只对 `img / svg / canvas` 生效，本项目 6 张里只有邮轮那张是真图，
选它会变成"只有一张能双击"；parallax 我做了（页面上有开关），但它更像装饰——history 才真正体现"轮播要和浏览器协作"。

### 但官方那套不能直接抄

照抄 `history: { key: 'exhibit' }` + `data-history` 之后，翻页和后退都对，**但地址栏变成了路径**：

```
…/swiper-demo/exhibit/neon      ← 不是 hash
```

静态站没有这个路由，**一刷新就是 404**；而且页面里 `css/style.css` 是相对路径，在 `/exhibit/` 这一层下会全部失效，整个页面裸奔。

### 我的改法：保留机制，换掉承载方式

```js
// 用户操作 → pushState（历史里新增一条，能按后退）；自动播放 → replaceState（不刷历史）
const state = { exhibit: i, slug };
userActed ? history.pushState(state, '', '#' + slug)
          : history.replaceState(state, '', '#' + slug);

// 后退 / 前进时，从 state 里取回是第几张
window.addEventListener('popstate', (e) => {
  const i = e.state && typeof e.state.exhibit === 'number' ? e.state.exhibit : -1;
  if (i >= 0) swiper.slideToLoop(i, 500);
});
```

实测结果：点下一张 → `#neon`（history +1）；再点 → `#liquid`（+1）；按后退 → 回到 `#neon`，停在第 2 张。

**为什么用 hash 不用 path**：hash 变化不会向服务器发请求，刷新、分享、收藏都安全；path 变化在静态站上等于向服务器要一个不存在的文件。

## 三、答辩四问

**Q1 这段代码什么意思？**

- `history.pushState(state, '', '#neon')`：往浏览器历史里塞一条新记录，地址改成 `#neon`，同时把"这是第几张"塞进 `state`；
- `popstate`：用户按前进/后退时触发，从 `e.state.exhibit` 取回索引，`slideToLoop(i)` 切过去——
  **不靠解析地址栏字符串，而是靠 state 里的结构化数据**，更稳；
- `replaceState`：同样改地址但**不新增**记录。自动播放用它，否则每 3.2 秒塞一条，用户按一次后退要按十几下才出得去。

**Q2 AI 第一次给的哪里不对、你改了什么？**

| AI 第一次给的 | 现象 | 我改成 |
|---|---|---|
| 照抄 340，pushState 路径 | 地址变 `/exhibit/neon`，刷新 404，相对路径全断 | 状态放 hash（`#neon`），刷新分享都不坏 |
| 只写 `history: { key }`，没给 slide 加 `data-history` | 模块跑起来了但取不到值，URL 出现空段，后退定位不到 | 属性和配置必须成对出现 |
| 自动播放也 `pushState` | 官方模块每次 `slideChange` 都 push，自动播放把历史刷爆 | 加 `userActed` 标志：只有用户操作后的切换才 push，其余 replace |

**Q3 新 API 的作用？**

`pushState(state, title, url)` 新增历史；`replaceState` 只改当前条；`popstate` 在前进/后退时触发，
`event.state` 就是当初 push 进去的对象；`slideToLoop(i)` 是循环模式下按"逻辑序号"跳转
（`slideTo` 用的是实际 DOM 序号，循环模式下会错位）。

**Q4 现场把 delay 改成指定值，预期是什么？**

| delay | 切换间隔 | speed=700ms 占一周期 | 观感 |
|---|---|---|---|
| 3200（默认） | 3.2s | 22% | 从容，每张停得住 |
| 1600 | 1.6s | 44% | 偏紧，翻页有点赶 |
| 800 | 0.8s | 88% | **动画还没走完就被推走，观感"卡带"** |

三句必须说出口：① `delay` 是"多久动一次"，`speed` 是"动多久"，不叠加；
② 改的是 `swiper.params.autoplay.delay`，要 `stop()` → `start()` 才会立刻按新值重新计时；
③ delay 不能比过渡时长小太多，否则视觉上就是"永远在动"。

## 五、思政衔接（30 秒，答辩收尾用）

前五件展品是 CSS 画的光——折射、霓虹、液光、光轨、光谱。第六件换成一张真实存在的东西：
**爱达·魔都号**，中国第一艘自己造的大型邮轮，13.55 万吨、323.6 米，2024 年 1 月 1 日从上海首航。

课上学的只是一个轮播插件，翻页、循环、缓动——都是"技术"。但这张图放在最后一页，是想说：
**技术本身没有温度，是把它用在什么地方、为谁而做，才让它有了温度。**

轮播会翻页，但奋斗者的故事永远自动播放。
