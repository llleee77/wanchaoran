第一部分：看代码找错 (20分)

下面代码存在 3 处 bug，错误位置与修改后的代码行已直接标出。

原始代码（含 3 处 bug）

.box li{ width: 300px; }
.box img{ width: 100%; }
.box li:hover img{ transform: scale(1.2); transition: all .6s; }
.txt{ position: absolute; bottom: 0; height: 40px; background: rgba(0,0,0,.6); }
.box{ display: flex; }

① 图片放大跑出卡片，盖住旁边卡片

错误位置：.box li 缺少 overflow: hidden，放大后的图片溢出未被裁切。

修改后的代码行：

.box li{ width: 300px; overflow: hidden; }

② 文字展开只有移入有动画，鼠标移出无过渡效果

错误位置：transition 写在了 :hover 状态里，而 .txt 默认选择器上没有过渡。

修改后的代码行：

.txt{ ... transition: all .6s; }  ← 写入默认选择器，而非 hover

③ 卡片布局排版错乱

错误位置：.txt 用了 position: absolute，父级 .box li 却没有定位（未满足子绝父相）。

修改后的代码行：

.box li{ width: 300px; position: relative; }

2.2 卡片动画补全

制作 6 张图文卡片，实现上图下文，悬浮图上文字展开效果。

需要实现效果 填写关键CSS代码 / 答案
防止放大图片溢出 li 容器 li 添加属性：overflow: hidden;
子绝父相，让文字条定位在卡片底部 li 添加属性：position: relative;
hover 图片从原始大小放大到 scale(1.2) 两个选择器：.box img（默认，可写 transform: scale(1)）与 .box li:hover img（写 transform: scale(1.2)）
文字高度平滑展开，移入移出都有动画。transition 写在默认还是 hover？为什么？ 写在默认选择器 .txt。因为 transition 写在 hover 上只在移入时生效，移出瞬间跳回无动画；写在默认状态移入移出都平滑渐变
奇数卡片悬浮，文字铺满整张卡片 使用伪类选择器：:nth-child(odd)（等价 :nth-child(2n+1)）→ .box li:nth-child(odd):hover .txt { height: 100%; }
补全后的完整参考代码：
.box li{
    width: 300px;
    position: relative;
    overflow: hidden;
    transition: all .6s;  /* 让文字条高度变化也能平滑过渡 */
}
.box img{ width: 100%; }
.box li:hover img{ transform: scale(1.2); }
.txt{
    position: absolute;
    bottom: 0;
    height: 40px;
    background: rgba(0,0,0,.6);
    transition: all .6s;
}
.box li:nth-child(odd):hover .txt{ height: 100%; }
.box{ display: flex; }

第三部分：手写原理简答 (25分)

答案已直接填入横线。overflow: hidden 两空为原题 2 小题的两条横线。

第 1 题 · 画图：父 position: relative，子 position: absolute 的盒子位置关系

第 2 题 · overflow: hidden 本节课两个作用分别是

  • 作用 1：裁切子元素溢出的内容（放大图片被封在卡片内，不遮挡旁边卡片）
  • 作用 2：清除浮动（触发 BFC/独立格式化上下文），解决父元素高度塌陷

第 3 题 · transform: scale(1.2) 会不会把盒子实际占位变大，挤压旁边卡片？说明原因

不会。transform 只是视觉上的缩放，不改变元素在文档流中的实际占位（宽高、边距不变），因此不会挤占相邻卡片空间。

第 4 题 · transition 写在 hover 上，和写在普通选择器上，鼠标移出动画有什么区别？

  • 写在 hover 上：只在鼠标移入时有过渡动画，移出瞬间恢复原样、无动画。
  • 写在普通选择器上：移入和移出都有对称平滑的过渡动画，故文字条移出也能平滑收回。

第 5 题 · 记录自己写代码遇到的 1 个 bug（不少于 30 字）

现象： 6 张图文卡片 hover 时图片放大约 1.2 倍冲出卡片，盖住右侧相邻卡片。
排查： 用元素检查发现被盖卡片宽度并未变化，确认是图片放大溢出 li；在样式面板中看到 .box li 只有 width，没有任何 overflow 裁切。
修复： 给 .box li 添加 overflow: hidden，并补上 position: relative 保证子绝父相，问题解决。

第四部分：扩展挑战（选做） (15分加分)

左下角回到顶部按钮，仅 CSS，无 JS。下方黑色按钮已实现该效果，可悬停体验。

回到顶部
页面内容（z-index 更低）
.back-top{
    position: fixed;      ← 固定定位，不随滚动移动
    left: 30px;
    bottom: 60px;
    width: 60px;
    height: 60px;
    background: #2563eb;
    border-radius: 50%;
    opacity: .5;          ← 初始半透明
    transition: transform .3s ease, opacity .3s ease;
    z-index: 999;          ← 浮于页面内容之上
}
.back-top:hover{
    opacity: 1;              ← hover 完全不透明
    transform: scale(1.1);  ← 轻微放大
}

HTML：<a href="#top" class="back-top">顶</a>，点击锚点 #top 回到页面顶部。
